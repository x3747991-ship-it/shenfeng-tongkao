## 核心方法论 · 病药说

张楠全书最核心的方法论：

> 有病方为贵，无伤不是奇；格中如去病，财禄两相随。

八字贵在有病（偏枯），有药（去病之神），行药运则富贵。无病则无药，有病无药则贫夭。**SK01 是所有格局技能的前置**，每个格局技能包内也已内嵌 SK01 的核心规则，可独立使用。

## 调用顺序

```
输入八字 → SK01 判断病药 → SK02-SK08 确定格局 → SK10 断事
                      ↓
                SK09 纠偏（可选）
```

1. **先调用 SK01**（元规则·病药八法）— 判断八字有病/无病、病在何处
2. **再调用对应格局技能**（SK02-SK08）— 根据月令和十神确定格局
3. **最后调用 SK10**（断事六亲）— 在格局确定后进行具体断事
4. **SK09**（谬说辨析）— 按需调用，用于鉴别命理说法的真伪

## 使用方法

### 方式一：作为参考文档阅读

直接阅读各 `SK*.md` 文件，学习张楠的病药说和格局断法。

### 方式二：导入 AI 助手使用

⚠️ **格式说明**：本仓库的技能文件是蒸馏产出的单文件 md（含「适用范围 / 工作原理 / 使用流程 / 规则集 / 参考命例」结构），**未包裹 SKILL frontmatter**。若要导入支持 SKILL 规范的 AI 助手（如 TRAE），需参考 [命学真典仓库](https://github.com/x3747991-ship-it/mingxue-zhendian) 的 `references/skill-template.md` 自行补充 frontmatter：

```yaml
---
name: shenfeng-sk01-bingyao
description: <60-120 字描述>
---
```

然后包裹为 `文件夹/SKILL.md` 结构即可导入。
